A readiness run that trusts this section without reconciling sprint-status would treat 8.9 as unstarted epic-only work. *Fix:* refresh the as-of date and change “8.9 `backlog`” to “8.9 `blocked`” (8.7/8.8 remain `blocked`; 8.10 remains `review`). Playwright a11y still lives in `tests/e2e` (including `parties-accessibility.spec.ts`) and bUnit still sits in portal/UI test projects, so the *capability* claim in NFR1/NFR9 mostly holds; the *job-name* claim does not. A readiness run looking for those five job names would report a missing gate. *Fix:* replace the five names with the current workflow/job set (`ci` → `build-and-test` plus the documented test tiers; keep Playwright `tests/e2e` and bUnit as the a11y evidence), or drop named jobs and point at `docs/ci.md`.

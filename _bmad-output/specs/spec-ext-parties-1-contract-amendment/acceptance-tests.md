No synthetic provider, returned flag, receipt-shaped JSON or test count proves installed destruction. Required failed, skipped, missing or unrun lanes fail qualification.

## Execution and evidence contract

Owners extend their existing test projects listed in implementation-plan.md. For local implementation validation, build individual target test projects in Debug using project references, then run the built xUnit v3 assemblies with single-dash -class/-method filters and fresh artifacts; do not use solution-level dotnet test. CI validates released package consumption in Release. No dependency versions or test commands against an invented package are pinned here.

Installed scenarios retain independently observed before/after unit identity/E, source head/segments, keys/generations, C01–C16 locations/outcomes/absences, holder scope/residuals, original operation/work/receipt bytes and journal, authoritative clocks/fences, actual backup cuts and positive live controls. Bind commands/argv/cwd/tool versions, authenticated operator/observer references, source/package/runtime images, installation/profile/configuration/plan/trust hashes and raw results. References are protected/minimized; logs contain no actor plaintext, DEKs, JWTs, login identifiers or secret values.

Use shortened intervals only on isolated explicitly authorized synthetic targets to exercise boundaries; separately validate actual production retention is 31,536,000 seconds and destruction/evidence bounds are the approved values. Test clock advancement is not proof that a provider's real immutable backup retention elapsed. Backend failure assumptions and independent assurance case must explain how observations support each hard bound; finite tests cannot prove universal physical erasure.

Drills require exact D03/D04 cut/target/principals and abort/disposal authority. Maximum fault duration is 10 minutes and verified disposal within 60 minutes after drill completion; neither extends data deadlines. No fault/destruction/deployment is authorized by this test plan. Existing eng/verify-ext-parties-1.ps1 Live refusal is preserved until a complete accepted target and real pass path exist.

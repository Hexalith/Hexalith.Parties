### Diff review findings

1. **Erasure status precedes committed events — fix now.**
   `PartyDomainProcessor.ProcessAsync` saves side status before returning its
   `DomainResult`, including terminal retry status
   ([PartyDomainProcessor.cs](../../src/Hexalith.Parties/Domain/PartyDomainProcessor.cs),
   lines 224-226 and 348-407). EventStore persists those events afterward
   (`references/Hexalith.EventStore/src/Hexalith.EventStore.Server/Actors/AggregateActor.cs`,
   lines 1321-1405). If append fails, the side record can claim `Verified` or
   `Erased` without a committed event; `PartySdkQueryService.cs` lines 169-177
   reads it first. Source-traced risk; no fault test was run. Route to Amelia,
   Winston, and Murat for committed-event reconciliation and a failure test.
2. **Search notifications can race erasure — fix now.** Live projection writes
   the index, then notifies search from a captured fold
   ([PartyIndexSdkProjectionHandler.cs](../../src/Hexalith.Parties.Projections/Handlers/PartyIndexSdkProjectionHandler.cs),
   lines 103-169). The eraser can remove that entry and notify search between
   those operations (`PartySdkReadModelEraser.cs`, lines 65-83 and 198-210).
   Rebuild completion also reads the index once before awaited removals and
   later indexed notifications (handler lines 282-324). The search adapter has
   no current erasure/version fence
   (`src/Hexalith.Parties/Search/PartyMemoryIndexEntrySearchIndexer.cs`,
   lines 35-75). This can republish erased data. The rebuild race is already
   D11 ([deferred-work.md](deferred-work.md), lines 1306-1308), while DW-80
   at lines 654-661 incorrectly says per-notification rereads resolved it.
   Route live and rebuild paths together to Amelia and Murat.
3. **Marker failure can mask destroyed-key typing — fix now.** The no-key
   branch catches a failed best-effort crypto-pending marker write and throws
   `PartyEncryptionKeyDestroyedException`. The outer catch attempts the same
   marker write again without preserving that exception
   ([PartyPayloadProtectionService.cs](../../src/Hexalith.Parties.Security/PartyPayloadProtectionService.cs),
   lines 532-562). Persistent marker failure masks the typed post-erasure
   redaction outcome. No marker-failure test was found. Route to Amelia and
   Murat for a guard and fault test.
4. **Authenticated projected-query proof remains open — defer.** The live
   gateway test stops at event count; routing tests replace the query router
   and handler tests use a substitute store
   (`EventStoreGatewayE2ETests.cs` lines 33-74,
   `EventStoreGatewayRoutingTests.cs` lines 1167-1168,
   `PartySdkQueryHandlerTests.cs` lines 33-51). This is already DW-30
   (deferred-work.md lines 251-257); no duplicate sprint action is added.

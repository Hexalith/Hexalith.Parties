## Intent

**Problem:** After deleting some mapped Memories units, `DeleteByPartyAsync` uses the caller's cancelled token to reconcile the mapping inventory. Cancellation can prevent completed progress from being saved and force later retries to repeat already completed deletions.

**Approach:** Reconcile only confirmed successful deletion targets through the existing exact-entry, concurrency-safe mapping removal using a bounded token independent of caller cancellation. Await reconciliation before propagating cancellation, preserve unfinished and concurrent mappings, and never report success after cancellation or a failed progress write. Keep normal mapping failures observable; when cancellation is already in flight, log a sanitized recovery failure without masking that cancellation. Verify persisted inventories, retry behavior, cancellation boundaries and recovery failure/timeout. Scope is DW-64; ingestion compensation, terminal workflow reconciliation and operational-ledger migration remain separate deferred work.
